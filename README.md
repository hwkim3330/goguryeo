# 고구려 高句麗 — 전장

브라우저에서 하는 고구려 실시간 전술 전투. 수천 명의 병사가 진형을 이루고 부딪칩니다.
개마무사의 돌격, 맥궁의 화살, 창수의 방진, 사기와 패주.

**플레이: https://hwkim3330.github.io/goguryeo/** (PC, 크롬/엣지 권장) · 허깅페이스: https://huggingface.co/spaces/kimhyunwoo/goguryeo

## 전투

- **살수대첩 (612)** — 살수(청천강)를 건너 북으로 퇴각하는 수나라 별동대를 여울에서 친다. 강을 건너
  북쪽 끝까지 빠져나간 적은 놓친다.
- **요동벌 회전 (645)** — 트인 벌판에서 당 태종의 군과 정면으로 맞선다.

## 병종

개마무사(중장기병, 돌격) · 기사(말 위 궁수) · 창수(대기병) · 환도수(방패와 고리자루칼) · 부월수(갑옷 파괴) ·
맥궁 궁수(각궁, 사거리 175 m) · 대장군(주변 사기 +). 수·당: 창병 · 도순수 · 궁노수 · 기병 · 장수.

## 어떻게 움직이나

- **병사 하나하나**가 부대 진형의 자기 자리로 걸어가다, 적이 닿으면 가장 가까운 적과 싸운다. 공격 · 방어 ·
  갑옷, 측면(+)·후면(++) 공격, 창의 대기병 보너스, 기병 돌격의 충격(창이 버티면 역으로 다친다).
- **화살**은 포물선으로 날아가 떨어진 자리의 사람을 맞힌다. 방패가 앞을 보고 있으면 막는다.
- **사기**는 손실 · 측면 · 돌격 · 사격 · 피로 · 장군의 유무로 오르내리고, 무너지면 달아났다가 안전해지면
  다시 모일 수 있다. 물(여울)은 느리고, 숲은 기병을 늦추고, 비탈은 오르기 힘들다.
- **그래픽:** 병사와 말은 부위별로 만든 인스턴스 메시를 정점 셰이더가 움직인다(걸음 · 베기 · 활 당기기 ·
  쓰러짐). 찰갑(비늘 갑옷)은 셰이더가 줄마다 그린다. 지형은 경사 · 높이 · 도로 · 강둑 마스크와 절차적
  노이즈로 칠하고, 바람에 눕는 수만 가닥의 풀, 깊이에 따라 색이 변하는 물, 구름 그림자, 대기 산란 하늘과
  반사, 먼지, 바람에 나부끼는 군기(삼족오 · 隋 · 唐), 블룸과 색 보정.
- **소리:** 모두 합성(북 · 각적 · 칼 부딪는 소리 · 화살 · 말발굽).
